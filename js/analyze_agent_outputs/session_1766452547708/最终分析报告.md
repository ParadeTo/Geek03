# 四川沱牌舍得集团有限公司财务数据分析报告

## 分析概述
本报告分析了四川沱牌舍得集团有限公司在2022至2024年度的财务数据，重点关注了公司主要财务指标的趋势变化。

## 关键发现
1. **毛利率趋势**：毛利率在2023年达到74.57%的高峰后，2024年下降至65.52%。这种波动可能由市场环境变化或成本上升导致。
2. **净利率趋势**：净利率从2022年的28.08%下降到2023年的25.03%，并在2024年显著下滑至6.35%，反映了公司盈利能力面临挑战。
3. **净资产收益率（ROE）趋势**：ROE在2022年为26.63%，随后逐年下降至2024年的5.08%，显示股东回报率降低。
4. **资产负债率趋势**：资产负债率在2024年上升到39.58%，表明公司财务杠杆和风险增加。
